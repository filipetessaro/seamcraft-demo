# Seamcraft Demo

Windows demo of **Seamcraft**, a render kit for Unreal Engine 5.6 to 5.8: mesh blending, bevel and snow, wet, moss
and dust cover, with no change to any material. The demo is the plugin's own showcase, packaged as a Shipping build
with UE 5.8.

**Download:** [SeamcraftDemo_Win64.zip](https://github.com/filipetessaro/seamcraft-demo/releases/latest/download/SeamcraftDemo_Win64.zip)
(770 MB). Windows 64-bit, DirectX 12. No engine needed.

Unzip it anywhere and run `SeamcraftDemo.exe`. You start over a granite rock set into a village yard.

| Key | What it does |
|---|---|
| G | Seamcraft on / off |
| B | Bevel on / off |
| C | Next cover: snow, wet, moss, dust, none |
| F | Walk on the ground and leave footprints in the cover (F again flies) |
| 1 to 5 | Viewpoints: rock in the yard, close to the same rock, rocks by the path, large rock, cabin yard |
| H | Hide the help text |
| Esc | Quit |

The top line shows what is on and the GPU time of the whole frame, so turning Seamcraft off shows what it costs.

The village is the Advanced Village Pack by Advanced Asset Packs, from Fab, and the rocks are Megascans. They are in the
demo only, not in the plugin.
